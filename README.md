# Janscob Gadgets Receipt & Invoice Studio

A mobile-friendly, installable receipt and invoice generator. No server or account is required.

## Features

- Cash receipts and sales invoices
- Quantity, product specifications, price, discount, delivery, payment and balance calculations
- Amount in words (Nigerian naira)
- Printable A4 receipt with the official Janscob Gadgets logo, watermark, signature spaces and no-refund note
- Editable store contacts, addresses and CEO signature
- Save, search, edit and duplicate documents
- Export and import customer-document backups as JSON
- Offline support after the first successful visit

## Publish on GitHub Pages

1. Sign in to GitHub and create a new repository, for example `janscob-receipts`.
2. Extract this ZIP and upload **all files directly to the root of the repository** (`index.html`, `app.js`, `styles.css`, `janscob-logo.png`, icons, and others).
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/(root)` folder, then save.
6. Open the GitHub Pages address shown in the Pages settings once publishing finishes.

GitHub's official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Install on your phone

- **Android Chrome:** Open the site → three-dot menu → **Add to Home screen** or **Install app**.
- **iPhone Safari:** Open the site → Share → **Add to Home Screen**.

## Important data information

Documents are stored in your current browser's local storage, **not on a central server**. Different phones do not automatically share records. Use **Brand settings → Export backup** frequently, especially before clearing browser data or changing devices. Use **Import previous backup** to move your saved documents to another phone.

PDF export uses your device's print dialog: tap **Print / Save PDF**, then select **Save as PDF**.

This package contains only the app. No customer records or personal sales data are included.
